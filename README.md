# AI News Customizer Dashboard 

Інтерактивний дашборд для автоматичної адаптації технологічних новин під різні сфери бізнесу за допомогою ШІ. 

Проєкт створено як прототип для демонстрації роботи з Gemini API. Інструмент аналізує вхідний текст та генерує структуровану аналітику (Специфіка, Задачі, Аудиторія, Ризики, Тон) для 6 ключових секторів.

## Технології
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+).
* **API:** Google Gemini API (модель `gemini-2.5-flash`).
* **Архітектура:** Односторінковий додаток (SPA) без використання зовнішніх фреймворків чи бібліотек.

## Ключові особливості (Features)
1. **Динамічний промптинг:** Система формує чіткий запит до LLM, вимагаючи відповідь у строгому JSON-форматі для зручного парсингу на клієнті.
2. **Відмовостійкість (Retry Logic):** Реалізовано алгоритм *Exponential Backoff*. У разі тимчасового перевантаження серверів Google (помилка 503), клієнт автоматично робить серію повторних запитів зі збільшенням затримки.
3. **Demo Mode (Fallback):** Якщо безкоштовний ліміт запитів до API вичерпано (помилка 429), додаток перехоплює помилку та безшовно перемикається на локальні mock-дані. Це гарантує, що користувач (або тестувальник) завжди отримає результат.
4. **CORS Bypass:** Для зручності локального тестування без підняття сервера, API-ключ передається безпечним для браузера способом.

## Як запустити локально
1. Склонуйте репозиторій або завантажте файл `index.html`.
2. Відкрийте файл `index.html` у будь-якому сучасному веб-браузері.
3. Оберіть новину з лівого меню, щоб запустити генерацію аналітики.

## Зауваження щодо безпеки (Security Note)
З міркувань безпеки та відповідно до політик Google Cloud, дійсний API-ключ не зберігається у цьому публічному репозиторії. Запити до LLM мають виконуватися на стороні сервера, а ключі не повинні "світитися" у клієнтському коді. У реальному production-середовищі всі запити до LLM та збереження ключів авторизації мають бути винесені на бекенд (або Serverless Functions).

**Як перевірити дашборд:**
1. Найпростіший спосіб: відкрийте файл `index.html` із **ZIP-архіву, надісланого на пошту** (до нього вшитий тимчасовий тестовий ключ, який буде деактивовано після перевірки).
2. Або клонуйте цей репозиторій та вставте власний Gemini API ключ у змінну `const API_KEY = "PASTE_KEY_HERE";`.
